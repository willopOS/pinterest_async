# Pinterest Async 📌

Réplica funcional y responsive de Pinterest desarrollada con JavaScript vanilla, SCSS y Vite, consumiendo de forma asíncrona la API de Unsplash.

## 🚀 Características

- **Diseño Responsive:** Cuadrícula adaptable multi-columna tipo Pinterest.
- **Arquitectura Modular:** Componentes reutilizables (`Header` y `Card`).
- **Consumo Asíncrono de API:** Búsqueda en tiempo real mediante `fetch` y `async/await` conectando con Unsplash.
- **Navegación Rápida:** Botón de reinicio en el logotipo para volver a la galería inicial.

## 🛠️ Tecnologías utilizadas

- HTML5 semántico
- SCSS / Sass
- JavaScript (ES6+ Modules)
- Vite
- Unsplash API
